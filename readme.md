> **Sistem Informasi Tryout CPNS Berbasis Web** - Platform simulasi ujian SKD CPNS dengan sistem CAT (Computer Assisted Test) yang realistis untuk membantu peserta mempersiapkan seleksi Calon Pegawai Negeri Sipil.

---

## 🎯 Tentang Proyek

**SISFO Tryout CPNS** adalah sistem informasi berbasis web yang dirancang khusus untuk **Oman's Club Academy** guna mendukung proses pelatihan dan simulasi ujian Seleksi Kompetensi Dasar (SKD) CPNS. Sistem ini dikembangkan sebagai respons terhadap kebutuhan akan platform tryout yang terintegrasi, otomatis, dan mudah diakses.

### Latar Belakang

Berdasarkan data Badan Kepegawaian Negara (BKN), pada tahun 2024 terdapat sekitar **3,9 juta pendaftar CPNS** dengan hanya **~250 ribu formasi** yang tersedia. Oman's Club Academy sendiri berhasil meluluskan **29 dari 60 peserta** (tingkat kelulusan ~48%) pada tahun 2024.

Untuk meningkatkan efektivitas pelatihan, sistem ini dikembangkan untuk mengatasi kendala:

| Kendala | Solusi Sistem |
|---------|----------------|
| ⏱️ Waktu koreksi yang lama | Penilaian otomatis real-time |
| 📝 Potensi kesalahan penilaian | Sistem terkomputerisasi akurat |
| 📊 Kesulitan monitoring peserta | Dashboard analisis lengkap |
| 🔄 Kurangnya simulasi CAT realistis | UI/UX menyerupai CAT BKN |

---

## ✨ Fitur Utama

### 👨‍💼 Admin Panel

| Fitur | Deskripsi |
|-------|-----------|
| 📊 **Dashboard** | Monitoring statistik peserta, tryout, dan nilai |
| 👥 **Manajemen Peserta** | CRUD data peserta, reset password, aktivasi akun |
| 📝 **Manajemen Tryout** | Buat, edit, jadwalkan, dan publikasikan sesi tryout |
| 📚 **Bank Soal** | Kelola soal TWK, TIU, TKP (tambah, edit, hapus) |
| 📈 **Nilai & Hasil** | Monitor performa peserta per sesi tryout |
| 📑 **Laporan Rekap** | Export data hasil tryout ke Excel |
| ⚙️ **Pengaturan** | Konfigurasi sistem dan passing grade |

### 👨‍🎓 Peserta Panel

| Fitur | Deskripsi |
|-------|-----------|
| 🏠 **Dashboard** | Ringkasan performa, nilai terbaik, rekomendasi |
| 🎯 **Ikuti Tryout** | Simulasi SKD dengan timer dan navigasi soal |
| 📜 **Riwayat** | Seluruh tryout yang telah diikuti |
| 📊 **Analisis** | Grafik perkembangan nilai per kategori |
| 👤 **Profil** | Kelola data diri dan ubah password |

### 🧪 Tryout Engine

- ⏲️ **Timer Otomatis** - Hitung mundur sesuai durasi tryout
- 🎲 **Pengacakan Soal** - Setiap peserta mendapat urutan berbeda
- 💾 **Auto-save** - Jawaban tersimpan otomatis
- 📝 **Penilaian Otomatis** - Nilai langsung keluar setelah selesai
- 🎯 **Analisis per Kategori** - Breakdown nilai TWK, TIU, TKP

---

## 🛠 Teknologi yang Digunakan

| Teknologi | Keterangan |
|-----------|------------|
| **PHP 8.0+** | Backend & Business Logic |
| **MySQL 8.0** | Database Management |
| **JavaScript ES6** | Frontend Interactivity |
| **Chart.js 4.4** | Data Visualization |
| **Bootstrap Icons** | Icon Library |
| **HTML5 & CSS3** | Struktur & Styling |
